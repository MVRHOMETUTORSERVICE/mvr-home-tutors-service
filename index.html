MVR HOME TUTORS SERVICE
“Connecting the right tutor with the right learner.”

A structured platform for Students, Parents and Tutors. Students and parents can create tuition requirements, tutors can build professional profiles and apply for suitable opportunities, and administrators can manage the service securely.

What do we do?

MVR Home Tutors Service organizes the complete tuition connection workflow in one place.

👨‍🏫 Tutors

Create a professional profile, add qualification, experience, subjects, classes and service areas, submit documents and apply for suitable tuition requirements.

👨‍👩‍👧 Students / Parents

Create a profile, post tuition requirements with subject, class, budget, timing and location preferences, and review tutor applications.

🛡️ Administration

Authorized administrators can review tutor information and documents and manage requirements, applications, notifications and reviews according to database security rules.

How It Works

Register → Verify → Complete Profile → Post / Apply → Connect.

1. Register & Verify

Create one account using your email and verify it using OTP.

2. Complete Profile

Enter role-specific information after login.

3. Tuition Workflow

Students/parents post requirements and tutors apply to suitable requirements.

Frequently Asked Questions

Who can register?

Students/Parents and Tutors can register. Admin login is separate.

How does OTP verification work?

Supabase Authentication sends the verification OTP to the registered email.

Can the same email create another account?

The system is designed for one Supabase Auth account per email. A duplicate registration is directed to Login.

What can a tutor add?

Qualification, experience, subjects, classes taught, teaching mode, service areas, bio and documents.

What can a Student/Parent do?

Create a profile, post tuition requirements and view/manage tutor applications.

Are sensitive tutor documents public?

No. Resume and identity documents are intended for private storage and authorized verification workflows.
